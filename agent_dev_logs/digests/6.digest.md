## 🎯 Goal
Map OCR lines onto a user-defined "vocabulary" (the TEATER topic taxonomy) via an LLM request, emitting structured keywords + confidences with paradata. Pipeline: `llm_run.py` (entry point) → `llm_pipeline.py` → `llm_utils.py` (shared), driven by `llm_config.txt`; vocabulary built by `vocab_sources.py` → `vocab_manager.py`, orchestrated by `vocab_build.py`.

### 🔑 The finding that changed the approach
Both sources **already ship the structure** the code was re-inventing, and both harvesters discarded it:

- **AMCR** — the OAI `heslo` record carries `nazev_heslare` (*which of the 50 controlled lists* a term belongs to), plus `ident_cely`, `popis`, `zkratka`, `razeni`, `hierarchie_vyse` and SKOS `odkaz` mappings. The old `fetch_amcr_vocab()` read `heslo` + `heslo_en` and dropped the rest — which is why a keyword matcher had to guess the grouping. The 7 themes are essentially a hand-rollup of those 50 lists.
- **TEATER** — the entire thesaurus is published as 12 static JSON files in [`ARUP-CAS/aiscr-teater`](https://github.com/ARUP-CAS/aiscr-teater) (and live at `/api/export`): **4134 concepts, 12 branches, trilingual, with the real broader/narrower tree**. So the flat TEATER vocabulary never needed "systematising into a nested one" by hand — it arrives nested.

## 🔧 What landed (`c8dc6de`, `c7b3472`)
Two stages, only the first needing the internet:

```
harvest (network)   →   FLAT artifacts    →   nest (pure)    →   NESTED artifacts
vocab_sources.py        *_flat.{json,csv}     vocab_manager      *_nested.json
```

- **`vocab_sources.py`** (new) — OAI-PMH walk with a hardened `lxml` parser (entity expansion + network off), TEATER snapshot pinned to a commit SHA, `VocabRecord` carrying ids/URIs/hierarchy/alt-labels/scope notes/SKOS mappings.
- **`vocab_build.py`** (new) — CLI: `--source both|amcr|teater`, `--from-flat` (offline re-nest, sub-second), `--check` (drift), `--stats`, `--update-legacy`.
- **`vocab_manager.py`** — `build_nested()` is now pure (no network, no disk); `assign_theme()` returns `(theme, rule)`; precedence `heslar_map → teater_branch_map → keyword → rescue → LLM (opt-in) → Other`; `load(auto_sync=False)` refuses to start a multi-minute harvest mid-run.
- **`taxonomy_config.json`** — `_settings` block: `heslar_map` (50 lists → theme, 6 marked `__exclude__`), `teater_branch_map` + labels (12 branches), `tie_break` (resolves the Methods 7 = Finds Context 7 and Find Types 5 = Location & Admin 5 ties that previously fell to dict order), and `Other` declared with `"in_prompt": false`.
- **`llm_run.py`** — `build_system_prompt(..., excluded_themes=...)` replaces the hard-coded `if theme.lower() == "other"`; the unreachable `other_cap=15` branch deleted — the TODO at [`../issues/2026-04-17.6.issue.open.md:675`](../issues/2026-04-17.6.issue.open.md) asked for its removal without noticing it had been dead since the `Other` exclusion went in.
- **Artifacts committed** under `data_samples/vocab/`: `*_flat.{json,csv}`, `{amcr,teater,union}_nested.json`, `*.meta.json` provenance sidecars, `*_placement_audit.csv`, `vocabulary.csv`. Paradata rows `amcr_vocab` / `teater_data` (CC BY-NC 4.0) added to `para_config.txt`; `.github/workflows/vocab-refresh.yml` harvests on a hosted runner (`create-pull-request` SHA-pinned in `c7b3472` after the hub's workflow linter rejected the `@v7` tag).

> ⚠️ **Not yet adopted.** `llm_config.txt:68` still reads `VOCAB_PATH=data_samples/teater_nested_vocab.json`, and that file is untouched since 2026-07-26 (`0b160e7`). Every LLM run therefore still sees the **488 + 1 meta = 489** terms @david-spacil measured. The union exists beside it, unused.

## 🔧 Implementation (Phase 1)
**vLLM backend** (commit `3e24876`) — `load_vllm_engine()` in `llm_utils.py`:
- `tensor_parallel_size` — auto-shards across N GPUs, no manual pipeline cuts.
- `enable_prefix_caching=True` — Automatic Prefix Caching: the system prompt (which embeds the **full vocabulary**) is computed once and its KV-cache reused for every line in every document → the primary throughput multiplier here. *Note for Phase 2: a bigger vocabulary makes this prefix bigger, so the union's ~25k tokens are paid once per run, not per line.*
- `guided_decoding_backend="xgrammar"` — native constrained JSON decoding (no `lm-format-enforcer`).

**Bug fixes** (Issue #6 items 7 & 8, commit `3e24876`):
- **#7 — silent abort with no marker.** On 10 consecutive errors the loop broke silently. New `_write_abort_marker()` writes a sidecar `<stem>_enriched.abort.json` (abort reason, lines processed, error count, UTC timestamp) regardless of partial results; `stats["aborted"]` added for programmatic checks.
- **#8 — empty `categ` passes unguarded.** In `_should_process_line` an empty string fell through every category guard. Explicit `if not categ:` branch now handles it with a labelled `[unknown categ]` skip.

Config / registry: new model entries and archived/deprecated models tracked in `llm_config.txt`; `vocab_manager.py` updates.
