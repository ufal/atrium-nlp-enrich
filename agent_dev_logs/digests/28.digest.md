## 🎯 Goal
Catch malformed TEITOK XML at the point of generation (end of `api_4_stats.sh`) so it never reaches downstream
visualizers, search indexes or the LINDAT release — the nlp-enrich counterpart of `atrium-translator`'s AMCR XSD gate.

## 🧭 Architecture (as built)
1. **Pinned schema** — `schemas/teitok/teitok.xsd` (no `targetNamespace`, because the writer emits
   `<TEI xmlnsoff="http://www.tei-c.org/ns/1.0">`) + a trimmed local `xml.xsd`; provenance, the format-2 table, the
   upstream-conformance section and the "how this schema went wrong once" history in `schemas/teitok/README.md`.
   **Hand-authored from `api_util/teitok_alto.py::write_teitok_merged()`** — no upstream TEITOK XSD/RNG/DTD exists
   in any of the TEITOK author's repositories, so there was nothing to vendor.
2. **Validator** — `api_util/validate_teitok_xml.py` (lxml, lazily imported): `rglob("*.teitok.xml")`,
   `[OK]`/`[FAIL]` + one diagnostic per violation, exit `0/1/2`, `--allow-empty`, `--quiet`,
   `--profile {xsd,core,wellformed}` (`--wellformed-only` = alias), `--exclude PATH` (repeatable); strips the TEI
   namespace first so legacy `xmlns=` documents validate against the same schema; points at `fix_teitok_bboxes.py`
   for the `</n>` quirk. `core` = TEITOK-core lint for *any* TEITOK profile: `<TEI>` root, `<text>`, unique `@id`
   on `tok`/`dtok`/`s` (missing ids allowed — flexiconv's split punctuation has none), `@head` resolves, no
   whitespace after a `join="right"` token, non-negative integer bboxes.
3. **Three emitters, three depths** —
   `stats` stage (`api_4_stats.sh` → `summarize_nt_udp.py` → `write_teitok_merged`): **full XSD, hard fail** over
   `$TEITOK_OUTPUT_DIR` minus `--exclude $TEITOK_FLEXICONV_DIR`, before `atrium_paradata.py finish` ·
   flexiconv (`api_flexiconv.sh`): **`--profile core`, hard fail**, own directory `$TEITOK_FLEXICONV_DIR` ·
   `POST /rescale`: **advisory** `schema_valid`/`schema_errors` in the response (`null` = not checked).
4. **CI** — `.github/workflows/teitok-schema.yml`: schema compiles → committed samples pass → valid fixtures pass →
   **negative test** (`CTX_invalid` must be rejected) → `pytest tests/test_validate_teitok.py` → flexiconv fixtures
   pass `--profile core` → `pytest tests/test_teitok_conformance.py tests/test_teitok_read.py` → install pinned
   flexiconv (core, lxml only) → conformance + flexiconv adapter tests again with the real flexiconv round-trip.

## ✅ What's settled
- Validator, schema, stage-4 hook, flexiconv hook, `/rescale` verdict and the named CI check exist on `test`
  (v0.18.3); the round-trip test that makes the real writer the arbiter stays the load-bearing part.
- 2026-09-23 branch: the XSD moved **with** the format-2 writer (mixed-content `tok` + `dtok`, `ord`, `sameAs`,
  `onto`/`archaeo`/`label`, optional `cnec`, `notesStmt`, `profileDesc`, `change@type/@subtype`, `pb@corresp`,
  `div@subtype/@lang`, non-negative `bboxType`) and still accepts format-1 documents
  (`tests/fixtures/teitok/legacy/CTX_format1.teitok.xml`).
- Fixtures `CTX_{valid,no_alto,invalid}` are now **real writer output** (`CTX_valid` has an MWT, a figure, an ALTO
  tag subtype); `data_samples/TEITOK/*` regenerated, and `test_committed_samples_are_what_the_writer_produces_today`
  fails when they drift from the code again.
- Upstream-conformance lane `tests/test_teitok_conformance.py`: stdlib reader following flexiconv's `load_teitok`
  rules (space = a space character in `tok.tail`) + optional pinned-flexiconv round-trip. Evidence on the regenerated
  samples: `SpaceAfter=No` 7/7, 16/16, 2/2 through flexiconv v0.3.10 (format 1: 0/7).
