## Context
Non-tabular documents are converted by flexiconv straight to TEITOK XML (replacing stages 2–4), and keyword
extraction / LLM enrichment read the resulting `.teitok.xml` through the stdlib `teitok_read`. The first real
conversions with the pinned flexiconv `v0.3.10` (2026-09-23) showed that flexiconv's TEITOK is **not
sentence-segmented** — plain formats give `<p>` text, layout formats (PAGE XML, hOCR, ALTO) give `<tok bbox>` inside
`<div>`/`<lb/>` — while `teitok_read` only understood `<s>`, so every converted document contributed **zero rows**. The
adapter also called a non-existent library function, let the CLI `pip install` extras mid-run, collided on shared
stems, and wrote into the directory the stage-4 XSD gate owns. All of it is fixed on the branch.

## Strategic actions

### A — Make converted documents readable ✅ (branch; decision 2026-09-23: reader fallback now)
1. `api_util/teitok_read.py` (single canonical copy; llm-enrich re-vendors it verbatim): rows `<s>` (prefer `@text`)
   → else `<lb/>`-delimited lines when the document has `<tok>` → else leaf blocks (`p head item cell l u ab quote`),
   page from `<pb>` (non-numeric `n` advances the counter); tokens with spacing = whitespace after `</tok>` (also
   across `</name>`/`<lb/>`) or `join="right"`/`spaceAfter="No"`; `<dtok>` text ignored; `upos` = `@upos` or `@pos`,
   never `@type`; untokenized documents → whitespace split with empty `lemma`/`upos`; `</n>` repair;
   `sentence_text()` helper (llm-enrich `xml_to_md`).
2. Fixtures captured from real `v0.3.10` output under `tests/fixtures/teitok/flexiconv/` + tests
   (`tests/test_teitok_read.py`). Caveat kept in the README: the legacy KER method needs lemmas.

### B — Fix the adapter and the conversion step ✅ (branch)
3. `api_util/flexiconv_convert.py` as in the digest (library `run_convert`, CLI fallback with `--no-auto-install`,
   timeout, typed errors, one-line `[FAIL]`, exit codes).
4. Output layout `TEITOK_FLEXICONV_DIR`; `<stem>.teitok.xml` / `<stem>.<ext>.teitok.xml`; `FLEXICONV_FORCE`.
5. `requirements_flexiconv.txt` extras pin.
6. `config_api.txt` (`FLEXICONV_FORMATS` += `xml hocr`, `TEITOK_FLEXICONV_DIR`, `FLEXICONV_FORCE`); `api_flexiconv.sh`

7. `para_config.txt`: `flexiconv = GPL-3.0 ; conditional ; …` (`para_licenses` canonicalises `-or-later` to `GPL-3.0`;
